# Task 1 - Responsive Landing Page

## Objective
Create a clean, responsive landing page using HTML and CSS.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Responsive Design

## Features
- Responsive header and navigation
- Hero section with heading, paragraph, and call-to-action button
- About section
- Services section using CSS Grid
- Contact section
- Footer with social links
- Responsive layouts for tablet and mobile screens

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` with Live Server, or open it directly in Chrome.
3. Resize the browser window to test responsiveness.

## Task Deliverables
- `index.html`
- `style.css`
- `README.md`
